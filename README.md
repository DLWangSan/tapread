# 点读 TapRead

面向长辈与阅读困难用户的 Android 全局文字朗读工具：复制文字后朗读，无需 OCR。

## 按系统自动分流

| 系统 | 默认方式 |
|------|----------|
| **Android 9 及以下** | 复制即自动朗读（后台监听剪贴板） |
| **Android 10 及以上** | 复制后点悬浮球；也可开无障碍实现复制即读 |

Android 10+ 系统禁止普通后台 App 读剪贴板，所以必须用悬浮球或无障碍。

## 功能

- 低版本：一键开启「复制即读」
- 高版本：悬浮球点读 + 可选无障碍自动读
- 系统 TTS、语速调节、试听
- 自动跳过过短文本与简单验证码

## 构建

```bash
./gradlew :app:assembleDebug
```
